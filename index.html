Sentinel AI Hackathon Project

A web-based disaster management platform designed to predict localized flood risks and support emergency response through machine learning, live meteorological data and interactive geospatial mapping.

Key Contributions

  • Built a full-stack disaster management platform using React, Vite, FastAPI and Python.
  • Integrated meteorological data from the Open-Meteo API.
  • Implemented an XGBoost machine learning model using 17 climate predictors to calculate probabilistic flood-risk scores.
  • Built interactive geospatial visualization using Leaflet.js.
  • Implemented role-based workflows for citizens, NGOs and administrators.
  • Added GPS-tagged SOS reporting for citizens.
  • Implemented Haversine-based distance calculations to determine whether users are within active hazard-zone radii.
  • Built administrative workflows for NGO verification and hazard-zone management.
  • Implemented dynamic hazard-zone generation based on current weather data.

How Sentinel AI Works

A visual representation of the disaster management workflow.

1. Weather Data → Fetching live metrics
2. 17 Climate Predictors → Normalizing inputs
3. XGBoost Model → Processing risk
4. Flood Risk Score → High probability detected
5. Hazard Zone → Polygon mapped on Leaflet
6. Distance Check → Haversine radius calculated
7. Emergency Response → Alerts dispatched to active users
