About Me

I am an entry-level Data Engineer with hands-on project experience building automated data workflows. I focus on developing reliable architectures that move data from raw ingestion to analytics-ready tables.

My work involves automated data pipelines, data ingestion, transformations, data quality validation, and data modeling. I utilize tools such as Python, SQL, PySpark, Databricks, AWS S3, REST APIs, and Delta Lake to process and structure data effectively.
