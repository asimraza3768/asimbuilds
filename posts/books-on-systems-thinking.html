How Reading Changes the Way We Build

October 28, 2026 | 3 min read

It is a common misconception that engineers only need to read technical documentation. While knowing the syntax of a language is important, understanding how to structure systems requires a broader perspective.

Systems Everywhere

When you read non-fiction books about habits, economics, or history, you start to see that everything is a system. A data pipeline is just a system of inputs, transformations, and outputs. Human habits follow the exact same loop: trigger, routine, reward.

Reading extensively outside of computer science has taught me how to think abstractly about flow, bottlenecks, and efficiency. It has taught me that writing code isn't just about making a machine do something; it's about organizing logic in a way that other humans can understand and maintain.
