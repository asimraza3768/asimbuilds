From REST API to Analytics Dashboard

September 30, 2026 | 6 min read

Connecting a data source to a dashboard sounds simple until you actually try to build it reliably. Here is the exact path data takes in my Job Market project.

The Extraction

It starts with a Python script hitting the JobsPipe REST API. It handles cursor-based pagination to loop through all pages of results, extracting JSON data for 5 different cities, and pushes the raw payload to an Amazon S3 bucket.

The Orchestration

A Databricks Workflow (consisting of 4 distinct tasks/notebooks) kicks off. Task 1 pulls the raw S3 JSON into a Bronze Delta table. Task 2 performs PySpark transformations and data quality checks, upserting into the Silver layer.

The Presentation

Task 3 runs SQL queries to aggregate the Silver data into 6 distinct Gold tables (e.g., skill counts, location groupings). Finally, Databricks AI/BI connects directly to these Gold tables to render the interactive dashboard in under 3 total minutes of runtime.
